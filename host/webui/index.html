Identify sweep

Lights one LED at a time on the physical pad. When you see which LED lit, click that position in the device view to record it. This is what turns the provisional index → position guesses into confirmed layout.key_positions / layout.underglow_positions.

Recorded key positions are [row, col] where col is the ordinal within that physical row, left to right — not the scan-matrix column. Which matrix columns the 2-key and 3-key rows populate is a separate unverified question (see docs/HARDWARE.md), so this UI deliberately does not assert one. Underglow positions are [x, y] in the 3×3 grid, 0–2 each, centre excluded.
